**SSC CGL Tier 1 & Tier 2**

## 1. Standard Trigonometric Values

| Angle ($\theta$)   | $0^\circ$ | $30^\circ$        | $45^\circ$        | $60^\circ$        | $90^\circ$ |
| :----------------- | :-------: | :---------------: | :---------------: | :---------------: | :--------: |
| **$\sin \theta$**  | $0$       | $\dfrac{1}{2}$    | $\dfrac{1}{\sqrt{2}}$ | $\dfrac{\sqrt{3}}{2}$ | $1$        |
| **$\cos \theta$**  | $1$       | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{1}{\sqrt{2}}$ | $\dfrac{1}{2}$    | $0$        |
| **$\tan \theta$**  | $0$       | $\dfrac{1}{\sqrt{3}}$ | $1$               | $\sqrt{3}$        | **ND**     |
| **$\csc \theta$**  | **ND**    | $2$               | $\sqrt{2}$        | $\dfrac{2}{\sqrt{3}}$ | $1$        |
| **$\sec \theta$**  | $1$       | $\dfrac{2}{\sqrt{3}}$ | $\sqrt{2}$        | $2$               | **ND**     |
| **$\cot \theta$**  | **ND**    | $\sqrt{3}$        | $1$               | $\dfrac{1}{\sqrt{3}}$ | $0$        |

## 2. Degree to Radian Conversion

| Degrees      | Radians           |
| :----------: | :---------------: |
| $0^\circ$    | $0$               |
| $30^\circ$   | $\dfrac{\pi}{6}$  |
| $45^\circ$   | $\dfrac{\pi}{4}$  |
| $60^\circ$   | $\dfrac{\pi}{3}$  |
| $90^\circ$   | $\dfrac{\pi}{2}$  |
| $180^\circ$  | $\pi$             |
| $270^\circ$  | $\dfrac{3\pi}{2}$ |
| $360^\circ$  | $2\pi$            |

**Formula:** $\text{Degrees} \times \dfrac{\pi}{180} = \text{Radians}$

---

## 3. Complementary Angle Identities

| Identity                                  |
| :---------------------------------------: |
| $\sin(90^\circ - \theta) = \cos \theta$   |
| $\cos(90^\circ - \theta) = \sin \theta$   |
| $\tan(90^\circ - \theta) = \cot \theta$   |
| $\cot(90^\circ - \theta) = \tan \theta$   |
| $\sec(90^\circ - \theta) = \csc \theta$   |
| $\csc(90^\circ - \theta) = \sec \theta$   |

---

## 4. Allied Angles (ASTC Sign Rule)

* **1st Quadrant ($0^\circ \text{ to } 90^\circ$):** **A**ll positive
* **2nd Quadrant ($90^\circ \text{ to } 180^\circ$):** Only **S**ine ($\sin, \csc$) positive
* **3rd Quadrant ($180^\circ \text{ to } 270^\circ$):** Only **T**angent ($\tan, \cot$) positive
* **4th Quadrant ($270^\circ \text{ to } 360^\circ$):** Only **C**osine ($\cos, \sec$) positive

---

## 5. Important Angle Relationships

* $\sin 0^\circ = \cos 90^\circ = 0$
* $\sin 90^\circ = \cos 0^\circ = 1$
* $\tan 45^\circ = \cot 45^\circ = 1$
* $\tan 30^\circ \times \tan 60^\circ = 1$
* $\sin 30^\circ = \cos 60^\circ = \dfrac{1}{2}$
* $\sin 60^\circ = \cos 30^\circ = \dfrac{\sqrt{3}}{2}$
